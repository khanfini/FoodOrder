# FoodOrder - سیستم سفارش غذا

یک برنامه مدیریت سفارش غذا مبتنی بر Django برای مدیریت سفارشات هفتگی کارمندان.

## ویژگی‌ها

- **مدیریت کاربران**: احراز هویت و مدیریت پروفایل کاربران
- **سفارش هفتگی**: امکان ثبت سفارش غذا برای روزهای هفته
- **پنل ادمین**: مدیریت منوها، سفارشات و کاربران
- **رپورت‌گیری**: گزارش‌های روزانه و هفتگی سفارشات
- **پشتیبانی از RTL**: رابط کاربری کاملاً فارسی و راست‌چین

## تکنولوژی‌ها

- **Backend**: Django 4.x
- **Database**: SQLite (پیش‌فرض) / PostgreSQL
- **Frontend**: HTML, CSS, Bootstrap 5, JavaScript
- **Authentication**: Django Auth System

## نصب و اجرا

### پیش‌نیازها
- Python 3.8+
- pip

### مراحل نصب

```bash
# کلون کردن مخزن
git clone https://github.com/khanfini/FoodOrder.git
cd FoodOrder

# ایجاد محیط مجازی
python -m venv venv
venv\Scripts\activate  # در ویندوز
# source venv/bin/activate  # در لینوکس/مک

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای میگریشن‌ها
python manage.py migrate

# ایجاد سوپریوزر (اختیاری)
python manage.py createsuperuser

# اجرای سرور توسعه
python manage.py runserver
```

## مدل‌های اصلی

- **UserProfile**: پروفایل کاربری با اطلاعات اضافه
- **FoodItem**: آیتم‌های منوی غذا
- **WeeklyOrder**: سفارشات هفتگی کاربران
- **DailyMenu**: منوی روزانه

## کمپین نظرسنجی غذا

یک کمپین چهار هفته‌ای که در آن هر هفته یک کترینگ غذا را سرو می‌کند و پرسنل به غذایی که خورده‌اند امتیاز می‌دهند.

- **امتیازدهی:** خوب، متوسط یا ضعیف، جداگانه برای غذای هر روز
- **روزهای قابل نظرسنجی:** فقط روز جاری و روزهای گذشته هفته جاری که کارمند برای آن‌ها غذا سفارش داده است
- **قفل روزانه:** بعد از ثبت نظر یک روز، همان روز با برچسب «ثبت شده» قفل می‌شود و دیگر قابل ویرایش نیست
- **سفارش هفته بعد:** در همان صفحه، منوی کامل هفته بعد (از جمله هر دو منوی پنج‌شنبه) برای انتخاب غذا نمایش داده می‌شود
- **صفحه ورود:** بنر تبلیغاتی کمپین همراه با موشن گرافیک SVG/CSS و نوار پیشرفت چهار هفته
- **تاریخ‌ها:** همه تاریخ‌ها به شمسی نمایش داده می‌شوند

### فایل‌های منوی هفتگی

فایل منوی هر هفته در پوشه `media/` با این الگو قرار می‌گیرد:

```
Menu_<سال><ماه>-w<شماره هفته>.xlsx
مثال: Menu_140509-w1.xlsx   (هفته اول آذر ۱۴۰۵)
      Menu_140509-w2.xlsx   (هفته دوم آذر ۱۴۰۵)
```

هر فایل ستون‌های `Date` (تاریخ شمسی مثل `1405/09/01`)، `Menu1` و `Menu2` دارد.

### مدل‌های کمپین

- **Catering**: کترینگ‌ها
- **Campaign**: هفته کمپین (کترینگ، شماره هفته، بازه تاریخ)
- **Survey**: امتیاز هر کارمند برای غذای یک روز

## دستورات مدیریت

```bash
# فعال‌سازی ادمین پیش‌فرض

python manage.py init_campaigns
```

# FoodOrder - سیستم سفارش غذا

یک برنامه مدیریت سفارش غذا مبتنی بر Django برای ثبت و مدیریت سفارش‌های روزانه و هفتگی کارکنان، نظرسنجی غذا و تهیه گزارش‌های مدیریتی.

## ویژگی‌ها

- **سفارش روزانه و هفتگی**: انتخاب منوی ۱، منوی ۲ یا «حضور ندارم» برای هر روز کاری؛ سفارش هفته بعد از صفحه سفارش هفتگی ثبت می‌شود.
- **انتخاب کارمند بر اساس دسترسی**: مدیران می‌توانند کارمند را انتخاب کنند؛ کاربران عادی فقط به کارکنان دپارتمان خود دسترسی دارند.
- **اصلاح سفارش توسط مدیر**: مدیر می‌تواند سفارش‌های هفته جاری را حتی پس از ثبت یا قفل‌شدن اصلاح کند.
- **مدیریت منوی هفته جاری**: مدیر می‌تواند نام غذاهای منوی هفتگی را از رابط برنامه ویرایش کند؛ تغییرات در فایل اکسل همان هفته ذخیره می‌شوند.
- **نظرسنجی غذا**: ثبت امتیاز خوب، متوسط یا ضعیف برای غذای روزهایی که سفارش داده شده است، با قفل جداگانه برای هر روز.
- **تاریخچه ماهانه**: نمایش انتخاب‌های کارمند، روزهای بدون سفارش و امتیازهای ثبت‌شده برای منوهای ماه جاری.
- **گزارش‌گیری مدیریتی**: گزارش‌های روزانه، هفتگی، بازه‌ای، تجمیعی و خروجی چاپی/اکسل.
- **صفحه ورود**: نمایش اطلاعیه کمپین فعال و بنر معرفی آن.
- **پشتیبانی از RTL**: رابط کاربری کاملاً فارسی و راست‌چین

## تکنولوژی‌ها

- **Backend**: Django 4.x
- **Database**: SQLite (پیش‌فرض) / PostgreSQL
- **Frontend**: HTML, CSS, Bootstrap 5, JavaScript
- **Authentication**: Django Auth System

## نصب و اجرا

### پیش‌نیازها
- Python 3.8+
- pip

### مراحل نصب

```bash
# کلون کردن مخزن
git clone https://github.com/khanfini/FoodOrder.git
cd FoodOrder

# ایجاد محیط مجازی
python -m venv venv
venv\Scripts\activate  # در ویندوز
# source venv/bin/activate  # در لینوکس/مک

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای میگریشن‌ها
python manage.py migrate

# ایجاد سوپریوزر (اختیاری)
python manage.py createsuperuser

# اجرای سرور توسعه
python manage.py runserver
```

## کمپین نظرسنجی غذا

یک کمپین چهار هفته‌ای که در آن هر هفته یک کترینگ غذا را سرو می‌کند و پرسنل به غذایی که خورده‌اند امتیاز می‌دهند.

- **امتیازدهی:** خوب، متوسط یا ضعیف، جداگانه برای غذای هر روز
- **روزهای قابل نظرسنجی:** فقط روز جاری و روزهای گذشته هفته جاری که کارمند برای آن‌ها غذا سفارش داده است
- **قفل روزانه:** بعد از ثبت نظر یک روز، همان روز با برچسب «ثبت شده» قفل می‌شود و دیگر قابل ویرایش نیست
- **صفحه سفارش هفتگی:** نظرسنجی، اصلاح سفارش هفته جاری برای مدیر، سفارش هفته بعد و کارنامه ماه جاری در دسترس هستند.
- **مدیریت منو:** مدیران و کاربران staff می‌توانند منوی هفته جاری را در مسیر `/manage/week-menu/` ویرایش کنند.
- **نمایش منو در گزارش‌ها:** منوی کمپین هفتگی مبنای نمایش نام غذا در سفارش‌ها و گزارش‌ها است؛ در نبود منوی کمپین، منوی عمومی استفاده می‌شود.
- **صفحه ورود:** بنر کمپین فعال و نوار پیشرفت هفته‌های کمپین نمایش داده می‌شود.
- **تاریخ‌ها:** همه تاریخ‌ها به شمسی نمایش داده می‌شوند

### دسترسی کاربران

- مدیران (کاربران staff یا superuser) می‌توانند کارمندان را انتخاب کنند، سفارش‌های هفته جاری را اصلاح کنند و منوی هفته را ویرایش کنند.
- کاربران عادی باید به یک دپارتمان متصل باشند و فقط می‌توانند برای اعضای همان دپارتمان سفارش یا نظرسنجی ثبت کنند.
- برای انتخاب کارمند، شناسه او از طریق فرم انتخاب کارمند در صفحه سفارش هفتگی ارسال می‌شود.

### فایل‌های منوی هفتگی

فایل اکسل منوی هر هفته در پوشه `media/` با این الگو قرار می‌گیرد:

```
Menu_<سال><ماه>-w<شماره هفته>.xlsx
مثال: Menu_140509-w1.xlsx   (ماه ۱۴۰۵/۰۹، هفته اول)
      Menu_140509-w2.xlsx   (ماه ۱۴۰۵/۰۹، هفته دوم)
```

هر فایل باید در ردیف اول ستون‌های `Date`، `Menu1` و `Menu2` داشته باشد. مقدار `Date` می‌تواند تاریخ شمسی مانند `1405/09/01` باشد. شماره هفته باید با شماره هفته ثبت‌شده برای کمپین مطابقت داشته باشد. ویرایش منو از صفحه مدیریت، ستون‌های `Menu1` و `Menu2` را در همین فایل به‌روزرسانی می‌کند.

### مدل‌های کمپین

- **Catering**: کترینگ‌ها
- **Campaign**: هفته کمپین (کترینگ، شماره هفته، بازه تاریخ)
- **Survey**: امتیاز هر کارمند برای یک روز
- **Order**: انتخاب منوی روزانه یا وضعیت عدم حضور کارمند
- **Department** و **Member**: دپارتمان‌ها و کارکنان قابل انتخاب برای سفارش


## مسیرهای اصلی

- `/weekly-order/`: سفارش هفتگی، نظرسنجی و تاریخچه انتخاب غذا
- `/manage/week-menu/`: مشاهده و ویرایش منوی هفته جاری (ویژه مدیران)
- `/admin/`: پنل مدیریت Django
- `/printable/` و مسیرهای گزارش: خروجی‌ها و گزارش‌های مدیریتی (ویژه مدیران)
